# 컨택싱어 관리자

컨택싱어 앱에 등록된 라이브바 사장님 · 가수 · 손님 정보를 보고, 팝업과 앱 설정을 바꾸는 관리자 사이트예요.

- 주소: https://ihlee456-dotcom.github.io/contactsinger-admin/
- 로그인: Supabase에서 만든 관리자 계정 (관리자 명단 `admins` 에 등록된 계정만 들어올 수 있어요)
- 검색엔진에는 노출되지 않아요 (`noindex`, `robots.txt`)

## 할 수 있는 일

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 사장님 · 가수 · 손님 수, 승인 대기, 오늘 신규 등록, 최근 등록 |
| 라이브바 사장님 · 가수 · 손님 | 검색, 상태별 보기, 상세 정보, 첨부 사진 · 사업자등록증, 승인 · 반려 · 차단, 메모, 삭제, 엑셀(CSV) 내려받기, 전화 · 문자 |
| 팝업 | 팝업 만들기 · 편집 · 켜기/끄기 · 삭제, 이미지 올리기, 대상(손님 · 사장님 · 가수) · 화면 · 기간 지정, 미리보기 |
| 앱 설정 | 공지 배너, 점검 모드, 기능 켜기/끄기 (신규 등록 · 예약 · 현장 팁 · 피드 · 공연 영상 · 컨택) |

## 파일

| 파일 | 설명 |
|---|---|
| `index.html`, `admin.css`, `admin.js` | 관리자 화면 |
| `config.js` | 서버(Supabase) 주소와 공개용 키. secret 키는 절대 넣지 마세요 |
| `robots.txt` | 검색엔진 수집 막기 |

## 보안

- 이 저장소는 공개돼 있어도 괜찮아요. 정보는 데이터베이스 권한 규칙이 지키고, 로그인한 관리자만 볼 수 있어요.
- 관리자 비밀번호는 다른 곳과 다르게, 길게 정해 주세요.
- Supabase › Authentication 설정에서 **새 회원가입 허용(Allow new users to sign up)** 을 꺼 두면 더 안전해요.
